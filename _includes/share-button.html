{% comment %} Icon-only share button. Used on video cards, sub-topic headings and the topic header — the icon carries the meaning, so no visible label. Params: class — classes for the button (always include "share-btn") label — accessible name and tooltip, e.g. "Copy link to this video" kind — "video" | "section" | "topic"; picks which link is copied vid — youtube id (kind: video) topic — topic id (kind: section) section — sub-topic id (kind: section) What to copy is carried in data attributes rather than an inline onclick: a single delegated handler reads them, and Jekyll's include tag cannot take a param value with nested quotes anyway. {% endcomment %}
